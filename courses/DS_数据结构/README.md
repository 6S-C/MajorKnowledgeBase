## 导入自己的DeepTutor

1. 安装DeepTutor，配置并测试自己的对话模型和Embedding模型。整理与验收时使用的DeepTutor版本为1.6.15。
2. 在Knowledge Center按上表分别创建五个LlamaIndex知识库。
3. 每个知识库只上传相应章节 **04_入库资料** 内的Markdown。不要把01、02、03和04重复全部上传。
4. 等待整批解析和索引完成，核对文档数和失败记录；随后在Chat中选择相应章节知识库。
5. 用概念题、指定习题和题量统计提问，检查实际来源。第二章题量应依据统计目录，不能从少数检索片段推算。

Git clone/pull同步的是资料文件，不会自动建立或更新DeepTutor索引。更新本地资料后仍需更新系统中的相应章节。

## 验证与资料边界

evaluation保存整理时的本机导入与检索验收记录，是历史验证证据，不是对所有模型回答的准确性保证。learning为待实际填写的学习记录模板；source-analysis为第一阶段源码阅读路线。代码测试可在相应代码目录运行：

```powershell
# 第2章，需要C++17编译器
g++ -std=c++17 -O2 test_chapter2.cpp -o test_chapter2.exe
./test_chapter2.exe

# 第3章，需要C99编译器
gcc -std=c99 -O2 test_chapter3.c -o test_chapter3.exe
./test_chapter3.exe
```

生成答案是辅助编写并核对的学习参考；题设歧义和表示约定已注明，最终仍应按授课教师口径复核。PPT图示、箭头和图片公式不一定被文本完整覆盖，须结合获准使用的原课件阅读。原始Word/PPTX未收入本仓库，原文件名与哈希保存在provenance中。

本仓库不含API密钥、模型权重、个人对话、运行环境和生成索引。课程资料原有权利归相应权利人；本仓库未额外授予原教材或教师课件的许可。
