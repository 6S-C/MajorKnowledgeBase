## 三、算法设计的共用约定

下列为C99，完整共用类型与ADT函数见本章05_提取与核对/代码验证/chapter3_reference.h。IntStack内部是固定数组，top表示元素数；IntQueue是无头结点链队列，QNode含data、next。所有链输入要求无环（题目指定循环的除外），sPop先判空、成功才写出参。与原卷部分题使用top=-1的约定不同，不能混用判空公式。

## 三-1、三-2．链栈元素数、链队列长度

链栈以top为首数据结点，链队列从first遍历；Θ(n)时间、Θ(1)辅助空间。空结构返回0。若带头结点，应从head->next开始，不计头结点。


```c
static size_t linkedStackCount(const QNode* top) {
    size_t count = 0;
    for (; top; top = top->next) ++count;
    return count;
}
static size_t linkedQueueCount(const IntQueue* q) {
    return linkedStackCount(q->first);
}
```

## 三-3．ClearStack

只用基本操作时反复Pop到空，Θ(n)时间、Θ(1)空间。C采用值传递，传IntStack*才能修改调用者的栈状态；若仅传整个结构的副本，清空只作用于副本。已知本表示时直接s->top=0可Θ(1)逻辑清空；若栈是动态链式且拥有结点，必须逐个释放，不能只丢弃头指针。


```c
static void clearStack(IntStack* s) {
    int x; while (sPop(s, &x)) { /* discard */ }
}
```

## 三-4．StackSize

原附解只用一次if只能统计至多1个，必须while。按值复制的是内嵌数组结构，不影响原栈；若含指针则浅复制未必安全。逐次Pop计数Θ(n)，已知表示直接返回s.top可Θ(1)。固定DS_CAP的结构复制为固定开销；把容量也当参数时应计其复制成本。


```c
static size_t stackSizeByOperations(IntStack s) { /* embedded array, safe value copy */
    size_t count = 0; int x;
    while (sPop(&s, &x)) ++count;
    return count;
}
```

## 三-5．圆括号匹配

遇左括号入栈，右括号先判空再弹出，扫描后必须返回栈为空；原附解返回!EmptyStack的逻辑反了。Θ(n)时间、Θ(n)辅助空间；如只判断单一圆括号，计数器也能用Θ(1)空间实现。


```c
static bool matchParentheses(const char* str) { /* only '(' and ')' matter */
    size_t n = strlen(str), top = 0;
    char* stack = (char*)malloc(n ? n : 1); if (!stack) abort();
    for (size_t i = 0; i < n; ++i) {
        if (str[i] == '(') stack[top++] = '(';
        else if (str[i] == ')') {
            if (!top) { free(stack); return false; }
            --top;
        }
    }
    bool ok = top == 0; free(stack); return ok;
}
```

## 三-6．Ackermann递归

定义A(0,n)=n+1；A(m,0)=A(m-1,1)（m>0）；A(m,n)=A(m-1,A(m,n-1))。输入是非负整数。下述直接递归仅供小输入实验，不保证大输入能在有限机器资源内算完，结果超unsigned long long会溢出；不要据“函数可计算”推断任意输入实用可算。A(1,n)=n+2，A(2,n)=2n+3，A(3,n)=2^(n+3)-3。


```c
static unsigned long long ackermann(unsigned m, unsigned long long n) {
    /* Mathematical definition. Only small test values: overflow/resources are bounded. */
    if (m == 0) return n + 1;
    if (n == 0) return ackermann(m-1, 1);
    return ackermann(m-1, ackermann(m, n-1));
}
```

## 三-7．循环队列长度

若数组长度capacity、保留一个空位、front与rear分别表示出队位置和下次入队位置，长度为`(rear-front+capacity)%capacity`，Θ(1)。满时为capacity-1；若用计数器使全部单元可用，就直接返回count，不能仅凭front、rear区分空与满。

## 四、基础知识

### 1．出栈序列

(1) 依题中`Push(1),Pop(),Push(2),Push(3),Pop(),Pop(),Push(4),Pop()`逐步模拟，输出 **1,3,2,4**。

(2) 1,4,2,3不可能：4弹出后3挡住2。1,4,3,2可行：I1,O1,I2,I3,I4,O4,O3,O2。

(3) 输入1,2,3,4的全部14种合法输出：

```text
1234 1243 1324 1342 1432
2134 2143 2314 2341 2431
3214 3241 3421 4321
```

### 2．链栈头结点

通常不设置以节省一个结点，直接在首结点入栈、出栈；设置头结点也合法，并非不能设置。空栈条件随之改变。

### 3．循环队列为何避免假溢出

线性数组队列rear到末端时，即使前部因出队出现空位，也可能无法再入队，称假溢出。循环取模使前部空位可再次利用。判空满可用：(a)牺牲一个单元；(b)额外满/空标志；(c)元素计数器。三种容量与判定条件不能混用。

### 4．单循环链队列用头指针还是尾指针

仅首指针：出队Θ(1)，入队一般需找尾Θ(n)；仅尾指针：通过rear->next取得首部，入队、出队均Θ(1)。空表和单元素需单独更新尾指针；有头结点时rear->next指向辅助头结点。

### 5．五段程序的原义与修正

(1) 原文`while(StackEmpty(S))`条件写反：非空时不进入、n=0，栈不变；空时进入后Pop下溢，不能正常求结果。修正为`while(!StackEmpty(S))`，补全变量类型及数组容量检查后，功能为逆置栈。

(2) S1→tmp，再逐项弹tmp并分别压入S1和S2：S1恢复原样；S2顶端追加一份与S1相同的栈底到栈顶次序。只有S2初始为空才是完整复制，必须有足够容量。

(3) 过滤并删除栈S中所有值为m的元素，其他元素相对次序不变。

(4) 先出队入栈，再出栈入队：逆置队列；原文&s与&S大小写不一致需更正。

(5) 第一轮Q1→Q2计数为m，但第二轮写i<n，n未定义，原程序不能正确执行。改成i<m、Q2初始为空时，Q1恢复、Q2得到同序副本。不能把原附解粘贴的“仅头指针/尾指针队列复杂度”当成本题答案。

## 四-5(1)修正代码

Θ(n)时间、Θ(n)所需数组容量，保留原元素集合。


```c
static void reverseStack(IntStack* s) {
    int a[DS_CAP], x; size_t n = 0;
    while (sPop(s, &x)) a[n++] = x;
    for (size_t i = 0; i < n; ++i) { bool ok = sPush(s, a[i]); assert(ok); }
}
```

## 四-5(2)修正代码

Θ(n)时间、Θ(n)所需临时栈容量；容量不足返回false且不改动两栈。


```c
static bool copyStack(IntStack* s1, IntStack* s2) { /* distinct stacks */
    if (s1->top > DS_CAP - s2->top) return false;
    IntStack tmp = {{0},0}; int x;
    while (sPop(s1, &x)) { bool ok = sPush(&tmp, x); assert(ok); }
    while (sPop(&tmp, &x)) {
        bool a = sPush(s1, x), b = sPush(s2, x); assert(a && b);
    }
    return true;
}
```

## 四-5(4)修正代码

Θ(n)时间、Θ(n)所需栈容量。


```c
static bool reverseQueue(IntQueue* q) { /* stack capacity must cover all q elements */
    IntStack s = {{0},0}; int x;
    size_t count = 0;
    for (const QNode* p = q->first; p; p = p->next) ++count;
    if (count > DS_CAP) return false; /* leave queue unchanged */
    while (qPop(q, &x)) { bool ok = sPush(&s, x); assert(ok); }
    while (sPop(&s, &x)) qPush(q, x);
    return true;
}
```

## 四-5(5)修正代码

Θ(n)时间；结果Q2占Θ(n)空间，额外工作变量Θ(1)。两个队列必须不同，Q2初始为空。


```c
static void copyQueue(IntQueue* q1, IntQueue* q2) { /* distinct; q2 starts empty */
    assert(qEmpty(q2)); int x; size_t m = 0;
    while (qPop(q1, &x)) { qPush(q2, x); ++m; }
    for (size_t i = 0; i < m; ++i) {
        bool ok = qPop(q2, &x); assert(ok);
        qPush(q1, x); qPush(q2, x);
    }
}
```
