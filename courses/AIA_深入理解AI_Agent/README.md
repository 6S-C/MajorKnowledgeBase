## 入库说明

建议按周或按主题建立知识库，只上传各周 `04_入库资料` 中的 Markdown 笔记。`evaluation/`、`learning/` 和 `weekly/` 用于实验复核与学习过程回顾，是否导入应根据知识库用途决定，避免与章节笔记形成重复检索。

## 实验记录口径

- 只把有实际日志或结果文件支持的内容写成已运行结果。
- 离线 mock、合成数据、仓库原有结论与本机在线调用分开描述。
- 失败、中断、未完成矩阵和假阳性均保留，不补造结果。
- 金额均为运行配置下的估算值，除非另有说明，不等同平台账单。
- 公开仓库不包含 `.env`、API Key、请求回执、原始运行目录、缓存、虚拟环境和模型权重。
