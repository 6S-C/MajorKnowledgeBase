# Obsidian 初步使用心得

这周开始用 Obsidian 整理学习资料。刚开始我把它理解成“更适合写 Markdown 的笔记软件”，实际用下来觉得它更像一个可以慢慢长起来的个人资料库：平时先把内容记下来，之后再通过链接和搜索把零散笔记串起来。

## 我现在主要怎么用

1. **按主题建立文件夹**  
   目前先按 Agent 学习、论文阅读、实验记录、课程学习和日常计划分类。这样刚开始找笔记比较直接，也不会因为目录太复杂而不想写。

2. **用 Markdown 记录，不追求一次写得很完整**  
   遇到一个概念、实验报错或论文中的疑问时，先用几句话记下来。后面理解更深入了，再补充公式、代码片段、结论或参考链接。这样比一开始就要求笔记“像正式报告”轻松很多。

3. **用双向链接把相关内容连起来**  
   比如在 AI Agent 的笔记中链接到“KV Cache”“提示注入”“第 2 章实验记录”，在论文笔记中链接到“EEGNet”“EEG-Conformer”“复现问题”。以后从一个概念跳到相关实验或论文会方便很多。

4. **用标签标记笔记状态**  
   现在准备先用少量标签，例如“待读”“进行中”“已完成”“待复现”“有疑问”。标签不宜一开始设得太细，重点是能看出哪些内容还没有处理完。

5. **用搜索和反向链接回看内容**  
   当我忘记某个概念在哪篇笔记里出现过时，直接搜索关键词比翻文件夹快很多。反向链接也能帮助我看到一个概念和哪些论文、实验或课程内容有关。

6. **用 Git 给笔记做版本管理和备份**  
   Obsidian 的笔记本质上是本地 Markdown 文件，适合用 Git 保存修改记录。对学习笔记来说，不一定要每次写一点就提交，但在完成一周学习、一次实验或一篇论文笔记后提交一次，会比较容易回看当时的思路。

## 目前感觉到的优势

我最明显的感受是，Obsidian 让“随手记”和“之后整理”可以分开。以前我经常因为觉得内容还没想清楚，就不愿意新建笔记；现在可以先记录问题，后面再补充，不会因为不完整而丢掉想法。

另外，学习内容之间的联系更容易保留下来。比如 Agent 的上下文工程、KV Cache 和提示注入原本是不同的小节，但通过链接能看到它们都和“模型每轮看见什么、能做什么”有关。论文阅读也是一样，模型结构、数据集、复现问题可以逐步连成一张自己的知识网络。

对我来说，Obsidian 目前最有价值的地方不是知识图谱看起来很酷，而是它把笔记、实验记录和待解决问题都放在一个可以持续维护的地方。配合 Git 后，后续修改也不会担心把旧内容覆盖掉。

## 接下来准备继续完善

1. 为论文阅读、实验记录和周报建立简单模板，减少每次新建笔记时的重复格式工作。
2. 继续整理 Agent、EEG/BCI 和数据结构相关笔记，并补充它们之间的链接。
3. 学习更实用的标签、查询和任务管理用法，但先保持结构简单，避免花太多时间“搭系统”而没有真正学习。
