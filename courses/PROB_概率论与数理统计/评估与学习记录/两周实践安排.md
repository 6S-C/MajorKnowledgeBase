# 前三章两周实践安排

这是从实际开始学习当天起的建议排期，非已经完成的成果或老师规定的数量。模型配置日期未定，因此用相对天数。

| 时间 | 学习与实践 | 留下证据 |
|---|---|---|
| 第1至2天 | 阅读第一章讲义，独立完成前7题 | 独立答案与条件概率错题 |
| 第3至4天 | 第一章其余8题，复核贝叶斯与独立性 | 至少一个错误推导的纠正过程 |
| 第5至6天 | 第二章讲义及前7题 | CDF端点与分布律计算 |
| 第7天 | 复习第一周，写周报 | 实际完成题目与未完成原因 |
| 第8至9天 | 第二章后8题，进入第三章联合分布 | 密度归一化、变量变换记录 |
| 第10至11天 | 第三章前8题 | 边缘、条件与独立性的推导 |
| 第12天 | 第三章后7题 | 函数分布的区域与分段 |
| 第13天 | 配置后导入资料，选择部分验证题实际使用；若模型仍未配置，则如实记录 | 导入与检索证据，或未执行状态 |
| 第14天 | 互测与分享，结合源码说明一次工具调用如何回填 | 5至10分钟演示、源码笔记、真实周报 |

周报建议写清：本周原计划、实际完成、可复核证据、存在的问题、下周补救。资料已生成不等于自己已学完，计算脚本通过不等于模型回答通过。
