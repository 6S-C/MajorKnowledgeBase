# DeepTutor导入与验收

版本v1.0.2；记录日期2026-10-25。
当前状态：资料包已准备；用户指定模型稍后配置。本轮没有创建实际知识库、上传文档、运行真实问答或进行检索评估。

## 配置完成后执行

1. 配置可用语言模型和嵌入模型，并各自测试连接。聊天可用不能证明嵌入可用。
2. 按课程资料/导入清单.csv创建三个章节知识库，每章4份Markdown，共12份。
3. 只选取04_入库资料中清单列出的文件，只使用各章04_入库资料。不重复上传讲义、题目版和答案版。
4. 等待每个文件处理完成，记录实际成功数和失败原因。预期数不等于实际数。
5. 绑定对应章节知识库，执行检索验证题.md中的问题，逐项检查引用与答案。
6. 问题数量核对题目索引.csv；模型说出45不能单独证明已完整读取资料。

## 可重建的CLI参考

以下命令仅供后续在实际安装版本中核实帮助后执行，本轮未执行。命令行支持情况以当前安装版`--help`为准。知识库名称可以沿用导入清单中的完整名称。

```powershell
deeptutor kb create 概率论_浙大第五版_第1章 --docs-dir '.\课程资料\第1章_概率论的基本概念\04_入库资料'
deeptutor kb create 概率论_浙大第五版_第2章 --docs-dir '.\课程资料\第2章_随机变量及其分布\04_入库资料'
deeptutor kb create 概率论_浙大第五版_第3章 --docs-dir '.\课程资料\第3章_多维随机变量及其分布\04_入库资料'
```

三章分库便于追溯；跨章学习时在聊天上下文中同时选中需要的库。文件内部的PROB-CHxx标识为资料定位，不是教材页码。

## 更新与移除

更新同一资料时保持文档ID，先核对哈希和版本，再按清单替换。保留实际知识库的名称、模型名、嵌入维度、安装版本和日期，不在共享资料中保存密钥或私人索引。
