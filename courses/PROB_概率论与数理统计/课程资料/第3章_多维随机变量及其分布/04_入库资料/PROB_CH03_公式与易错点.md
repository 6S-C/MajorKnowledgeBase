# 第3章 公式与易错点

版本v1.0.2，原创速查资料。符号$f(x,y)$表示完整联合密度，包含其支持集限制。

| 用途 | 公式 | 条件与核对 |
|---|---|---|
| 联合CDF | $F(x,y)=P(X\le x,Y\le y)$ | 任意矩形增量非负 |
| 离散边缘 | $p_X(x_i)=\sum_jp_{ij}$ | 消去另一坐标 |
| 连续边缘 | $f_X(x)=\int f(x,y)dy$ | 上下限按支持域确定 |
| 离散条件 | $p_{X\mid Y}(x_i\mid y_j)=p_{ij}/p_Y(y_j)$ | 分母概率为正 |
| 连续条件 | $f_{X\mid Y}(x\mid y)=f(x,y)/f_Y(y)$ | 在适用位置$f_Y(y)>0$，不是用单点概率相除 |
| 独立的一般判据 | $F(x,y)=F_X(x)F_Y(y)$ | 对全部x、y成立 |
| 独立密度判据 | $f(x,y)=f_X(x)f_Y(y)$ | 几乎处处成立，不能漏掉支持限制 |
| 和的一般公式 | $f_{X+Y}(z)=\int f(x,z-x)dx$ | 有联合密度，区间随z改变 |
| 独立时的卷积 | $\int f_X(x)f_Y(z-x)dx$ | 先确认独立 |
| 最大值CDF | $F_X(z)F_Y(z)$ | X、Y独立 |
| 最小值CDF | $1-[1-F_X(z)][1-F_Y(z)]$ | X、Y独立 |
| 商的密度 | $\int |y|f(zy,y)dy$ | 商有定义且可用密度变换，注意分母为零 |
| 积的密度 | $\int_{x\ne0}|x|^{-1}f(x,z/x)dx$ | 有效支持区域与雅可比 |

## 连续联合题的操作顺序

1. 写出支持域的不等式，确认常数归一化。
2. 固定一个坐标，求另一个坐标的上下限。
3. 求边缘；条件题再除以相应边缘密度。
4. 独立题保留完整支持限制；函数分布题与新事件域取交。
5. 检查新密度面积、CDF单调性与端点。

## 易错辨析

- 两个边缘相同不代表两个变量独立。
- 两个边缘都正态不保证联合正态。
- 二维正态中零参数rho与独立的关系，依赖已知联合正态模型。
- 单位正方形均匀抽点时，两个坐标的和通常不是均匀分布。
- 密度在一个三角形内恒定，不代表两个坐标独立。
- 条件密度的支持区间可能随条件值变化。

## 三章之间的联系

先用第一章的事件概率描述区域，再用第二章的CDF表示数值阈值，最后利用联合分布计算多个变量的关系。遇到快捷公式不确定时，回到CDF和支持区域。
