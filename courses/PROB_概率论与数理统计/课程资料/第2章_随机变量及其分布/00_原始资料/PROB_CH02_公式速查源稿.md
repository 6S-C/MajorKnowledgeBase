# 第2章 公式与易错点

版本v1.0.0，原创速查资料。所有分布先写支持集和参数约定。

| 用途 | 公式 | 条件与核对 |
|---|---|---|
| 离散归一化 | $p_i\ge0,\sum_i p_i=1$ | 支持点不能遗漏 |
| 分布函数 | $F(x)=P(X\le x)$ | 单调不减、右连续、两端极限0和1 |
| 左开右闭区间 | $P(a<X\le b)=F(b)-F(a)$ | 任意实随机变量，a<b |
| 闭区间 | $P(a\le X\le b)=F(b)-F(a^-)$ | 左端用左极限 |
| 单点质量 | $P(X=a)=F(a)-F(a^-)$ | 混合与离散分布尤其重要 |
| 连续密度 | $P(a<X<b)=\int_a^bf(x)dx$ | 存在普通密度时单点概率为0 |
| 二项 | $\binom nkp^k(1-p)^{n-k}$ | $k=0,\ldots,n$，独立同成功率 |
| 泊松 | $e^{-\lambda}\lambda^k/k!$ | $k=0,1,\ldots$，$\lambda>0$ |
| 几何（补充） | $(1-p)^{k-1}p$ | 首次成功次序，从1开始 |
| 均匀 | $f(x)=1/(b-a)$，$a<x<b$ | $a<b$，区间外密度0 |
| 指数 | $f(x)=\lambda e^{-\lambda x}$，$x>0$ | 本包用率参数，$\lambda>0$ |
| 正态标准化 | $Z=(X-\mu)/\sigma$ | $X\sim N(\mu,\sigma^2)$，$\sigma>0$ |
| 函数CDF法 | $F_Y(y)=P(g(X)\le y)$ | 先定新支持集，再解不等式 |
| 单调密度变换 | $f_Y(y)=f_X(h(y))|h'(y)|$ | 有效逆函数与支持条件，非单调时分支求和 |

## 常见错误

- 密度值可以大于1，概率必须通过积分计算。
- 正态第二参数为方差，标准化用其平方根。
- 指数率参数和尺度互为倒数，不能直接混用。
- 平方变换可能有两个逆像；递减变换会反转不等号。
- CDF在跳跃点右连续，单点质量来自跳跃，不来自导数。
- 混合分布不能仅靠连续部分的普通密度描述。

## 答案的最低检查

分布律总和为1，密度积分为1，CDF不下降；CDF在新变量取值范围外取0或1。遇到异常先检查支持集和端点，暂不急于化简式子。
