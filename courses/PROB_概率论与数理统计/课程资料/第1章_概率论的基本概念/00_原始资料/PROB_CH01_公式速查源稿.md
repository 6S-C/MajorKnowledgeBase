# 第1章 公式与易错点

版本v1.0.0，原创速查资料。使用前先明确事件与假设。

| 用途 | 公式 | 条件与核对 |
|---|---|---|
| 补事件 | $P(A^c)=1-P(A)$ | 补集相对同一个样本空间 |
| 加法 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ | 交集通常不能省 |
| 等可能计数 | $P(A)=|A|/|\Omega|$ | 有限、基本结果等可能、计数口径一致 |
| 条件概率 | $P(A\mid B)=P(A\cap B)/P(B)$ | $P(B)>0$ |
| 乘法 | $P(A\cap B)=P(B)P(A\mid B)$ | 不需要独立，但条件概率须有定义 |
| 全概率 | $P(A)=\sum_iP(B_i)P(A\mid B_i)$ | 各来源互斥、穷尽且有正概率 |
| 贝叶斯 | $P(B_j\mid A)=P(B_j)P(A\mid B_j)/\sum_iP(B_i)P(A\mid B_i)$ | 另外要求结果A有正概率 |
| 两事件独立 | $P(A\cap B)=P(A)P(B)$ | 定义可覆盖零概率事件 |
| 恰好k次成功 | $\binom nk p^k(1-p)^{n-k}$ | n次相互独立、同成功率、二结果 |
| 至少一次成功 | $1-(1-p)^n$ | 同上，先找“全失败”的补事件 |

## 错误纠正

- “P(A|B)等于P(B|A)”：先写交概率再分别除以条件事件，二者一般不同。
- “互斥所以独立”：正概率互斥事件的交为零，但概率乘积为正。
- “两两独立就是相互独立”：三个事件还要检查三重交。
- “无放回也可直接套二项分布”：后次抽取的条件分布通常改变。
- “概率为零就是不可能”：连续变量的指定单点提供反例。
- “只看事件结果个数就能等可能计数”：不同记录值可能合并了不同数量的基本结果。

## 自己解释给同学听

用一张来源分支表解释全概率与贝叶斯：向前汇总得到结果概率，观察结果后重新归一化得到来源概率。说明每一个乘法因子的含义，而不只背公式。
