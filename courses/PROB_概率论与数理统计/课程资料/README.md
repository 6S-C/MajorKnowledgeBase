## 阅读与练习

1. 先读各章01_课件中的原创学习讲义。
2. 用02_题目独立作答，再用03_答案与解析核对。
3. 在评估与学习记录/学习记录.md记录实际学习与错题，未做的练习不要写成已完成。
4. 复习时查看各章04_入库资料中的公式与易错点。
