## 二、算法分析与评价

1. `i=0…n,j=0…m`：赋值 (n+1)(m+1) 次，Θ((n+1)(m+1))；n,m都增大时简写 Θ(nm)。
2. 两重 n 次循环：n² 次累加，Θ(n²)。
3. `i*=3`：⌊log₃n⌋+1 次，Θ(log n)，n≥1。
4. `fact(n)`：T(n)=T(n-1)+Θ(1)，Θ(n)时间，Θ(n)递归栈空间，假定非负整数且结果可表示。
5. 反复求 i! 再求和：乘法 1+2+…+n=n(n+1)/2 次，Θ(n²)时间，Θ(1)辅助空间；原代码需声明 `p`。若保留前一次阶乘，能改进为 Θ(n) 次乘法，但那是另一算法。

## 三、综合题

### 1．八个概念

数据是可处理的信息表示；数据元素是处理的基本单位；数据类型是值的集合及其操作；数据结构是数据元素集合及相互关系。逻辑结构描述抽象关系；存储结构描述具体表示。线性结构的非空序列具有唯一首元素、尾元素，其余元素各有一个直接前驱/后继（单元素时首尾相同）；非线性结构不满足这种整体线性关系，例如树、图。不能要求非线性结构的每个结点都有多个前驱或后继。

### 2．实例的三个方面

班级成绩表：每条学生记录是一个元素，按学号排序后构成线性关系；可用连续数组或链表存储；支持查询、插入、删除、修改及统计成绩。逻辑顺序、具体地址、运算接口要分别说明。

### 3．四种常用存储方法

顺序存储以连续位置表示关系；链式存储用指针/下标表示链接；索引存储建立额外索引表以定位记录；散列存储由关键字通过散列函数定位桶/地址，并处理冲突。

### 4．f、g、h 的大O关系

(1)成立，(2)成立：f,g均为Θ(n³)，比值趋于4和1/4。(3)成立，因为 n log n / n^1.5 = log n / √n →0，h=Θ(n^1.5)。(4)不成立，因为 √n/log n→∞，h不是O(n log n)。

### 5．100n²首次快于2ⁿ

正整数 n 的最小值为 **15**。n=14时19600>16384；n=15时22500<32768。对n≥3，比值2ⁿ/(100n²)每次乘以2(n/(n+1))²>1，因此过此交点后继续成立；n=1,2也不满足。

### 7．复杂度只与规模有关吗？

具体运行次数还受输入内容和排列影响，如顺序查找目标在首项还是末项。固定n后取最大值、最小值或按指定分布求期望，才得到最坏、最好或平均复杂度函数。写时间复杂度时应交代分析口径。

### 8．渐近增长从小到大

`(2/3)^n < 2^100 < lg n < n^(3/2) < n^(lg n) < (3/2)^n < 2^n < n! < n^n`，指n充分大、lg为底2的对数。原附解把不等号写反，还插入了题目没有的√n；不能照抄。

### 9．保留主项系数比较

| 函数 | 表示 | n充分大时的次序 |
|---|---|---|
| T1 | 5n²+O(n) | 第3 |
| T2 | 3n²+O(n) | 第2 |
| T3 | 8n²+O(log n) | 第4 |
| T4 | 1.5n²+O(n log n) | 第1 |

渐近时间从少到多为T4、T2、T1、T3；四者都是Θ(n²)。常数6000可能使T4在较小n时并不最快。题干示例`2.0n lg n-2n`应写成`2.0n lg n+O(n)`，不能漏掉n。
