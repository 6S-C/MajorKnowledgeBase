## 💡 本周思考

**从一次循环出发，理解 Agent 的工作方式。** 
本周围绕第 1 章建立整体认识：用户任务进入上下文，模型决定下一步动作，程序执行工具，再把结果交回模型继续判断。学习重点是理解每轮决策依赖的信息，以及任务在什么条件下结束。后续阅读实现时，我会沿着这条信息流找入口、状态变化和验证环节。

**把上下文当作一份需要管理的信息清单。** 
通过 `context` 实验，我观察到 `full` 用 3 轮、4 次工具行动正确完成任务；`no_history` 和 `no_tool_results` 都重复调用并达到 5 轮上限。`no_reasoning` 本次仍然正确，说明不能把教材中的预期退化直接当作每次运行都会出现的结论。记录时还需要分清“程序返回了回答”“答案正确”“答案有依据”，并检查自动评分的单位和精度口径。

**把工程习惯落实到日常编程与实验。**  
未来可以把文件整理、数据处理和结果汇总等重复任务封装为工具，让 Agent 调用并检查结果。这个过程需要明确输入参数、返回格式、错误处理和验证条件。本周对工具调用协议和 Harness 的学习，让我开始关注程序如何处理失败、判断任务是否完成，以及怎样通过日志和对照实验验证改动的效果。

**读论文时重点看比较条件。**  
本周重点阅读 FBCNet 和 EEG-TCNet 两篇论文，分别从频谱—空间特征与轻量时序卷积切入。整理过程中我意识到，模型准确率只有放在相同的数据集、被试划分、预处理和评价指标下才有比较意义。后续阅读时，我会先确认实验设置，再分析网络结构带来的改进，避免只根据结果表判断模型优劣。

按 W0 排期学习 `book/chapter1.md`，梳理 **4 个核心主题**：

| 核心主题 | 本周整理的认识 |
| :--- | :--- |
| Agent 三要素 | LLM 负责判断，上下文提供可见信息，工具负责与外部环境交互 |

### （二）Starter 实验：上下文组件的作用

围绕 `chapter1/context` 完成 **1 项 Starter 实验**，使用 DeepSeek 官方 API 对同一个多币种收入计算任务运行全部 **5 种上下文配置**。五组均保存了逐轮请求与响应，仓库验收结果为 `experiment_execution_accepted=true`。

| 配置 | 迭代数 | 工具行动数 | 结果 |
| :--- | ---: | ---: | :--- |
| `full` | 3 | 4 | 正确完成 |
| `no_history` | 5 | 15 | 重复调用，达到迭代上限 |
| `no_reasoning` | 3 | 4 | 正确完成，本次未观察到退化 |
| `no_tool_calls` | 1 | 0 | 未编造汇率，但无法完成计算 |
| `no_tool_results` | 5 | 7 | 重复与试探调用，达到迭代上限 |

正式五组运行累计使用 **23,338 Token**，其中输入 18,889、输出 4,449、缓存命中输入 14,976。实验说明了历史消息保存任务进度、工具结果形成反馈闭环；同时保留 `no_reasoning` 没有退化这一负面结果。

### （三）实验1-2：观察完整的ReAct搜索轨迹

运行`chapter1/web-search-agent`提供的`offline-demo`，观察一条关于Context Caching的预置搜索轨迹。程序成功输出并保存 **2次思考、2次`web_search`行动、2条工具观察和1个最终答案**，相关定向测试 **7/7通过**。

第一次搜索用于确认概念定义，模型读取观察后发现仍缺少适用场景，于是发起第二次搜索，最后综合两次观察作答。这条轨迹让我更清楚地区分了三个环节：模型负责提出行动，程序负责执行工具，工具结果作为观察重新进入上下文。第二轮决策依赖第一轮观察，因此“调用了工具”和“利用了工具结果”是两个不同的判断条件。

本次运行不调用API，也没有产生Token或费用。搜索结果来自仓库预置数据，所以状态记为**已运行（离线演示）**，不写成真实联网搜索或Kimi K3实测。详细记录见[实验1-2离线演示记录（详见本周附件）](朱家鹏09-28至10-04周报附件.zip)。

### （五）论文阅读：MI-EEG 模型路线对比

本周重点阅读并整理 **2篇运动想象 EEG 方向论文**：FBCNet 和 EEG-TCNet。前者代表频谱—空间多视图建模，后者代表轻量时序卷积，两条路线互补。

| 阅读方向 | 对应论文 | 本周形成的认识 |
| :--- | :--- | :--- |
| 频谱—空间特征 | FBCNet | 理解滤波器组、多视图卷积和 Variance Layer 如何组合频带与空间信息 |
| 轻量时序建模 | EEG-TCNet | 关注 TCN 的时间依赖建模、低参数量与嵌入式部署价值 |

本周完成两条模型路线的初步比较，没有把论文报告的准确率写成个人复现结果。下一步将补齐两篇论文的数据集、划分方式、输入形状、参数量和评价指标，为后续代码阅读或复现建立一致的比较口径。
