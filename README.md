## 仓库结构

```text
仓库根目录/
├─ README.md                         团队课程总览
├─ 团队课程知识库整理与交付规范.md    所有课程共同遵守的规范
├─ .gitignore
├─ .gitattributes                     跨系统统一文本换行
└─ courses/
   ├─ PROB_概率论与数理统计/           概率论课程资料
   └─ DS_数据结构/
      ├─ README.md                   本课程说明和导入步骤
      ├─ 答案导航.md
      ├─ chapters/                   分章课件、题目和答案
      ├─ evaluation/                 本课程导入与检索验收
      ├─ learning/                   本课程学习记录
      ├─ provenance/                 本课程来源与文件映射
      └─ source-analysis/            本课程源码阅读资料
```

## 提交其他课程

1. 阅读[团队课程知识库整理与交付规范](团队课程知识库整理与交付规范.md)。
2. 每门课新建独立目录，例如 `courses/PROB_概率论与数理统计/`。把该课程的README、资料和验收记录全部放在里面。
3. 在 `course/课程代码` 分支提交，发起Pull Request。提交范围限定在自己负责的课程目录。
4. 管理员检查并合并后，课程文件会出现在main；课程总览由管理员统一补充。

课程负责人维护课程内README；共享规范和仓库根README由管理员统一维护，减少多人同时修改同一文件造成的冲突。

## 导入DeepTutor

进入对应课程目录，按课程README操作。数据结构按章建库，只上传各章 `04_入库资料` 中的规范文件。

GitHub保存的是课程资料；拉取或合并文件后，仍需在自己的DeepTutor中导入或更新索引。课程分目录不会改变DeepTutor中的现有知识库。
